# Реализация поддержки связанных сущностей в реактивной библиотеке доступа к данным

## Цель

Снижение трудоемкости разработки и поддержки слоя доступа к данным в реактивных серверных приложениях

## Задачи

Анализ существующих подходов и выявление архитектурных ограничений при работе со связанными сущностями в средствах реактивного доступа к данным. Проектирование структуры метаданных, алгоритмов неблокирующего извлечения данных и архитектуры программного модуля расширения для библиотеки Spring Data R2DBC. Разработка механизмов автоматической генерации SQL-запросов и декларативной сборки графа объектов из плоских результирующих наборов без блокировки потоков исполнения. Тестирование корректности работы реализованного механизма загрузки связанных сущностей в рамках экспериментального серверного приложения. Оценка результатов применения разработанного модуля и сравнение предложенного решения с ранее применявшимися подходами с точки зрения снижения сложности разработки.

## Перечень подлежащих разработке вопросов

Анализ предметной области и ограничений спецификации R2DBC в контексте загрузки связанных сущностей; выбор подхода к декларативному описанию объектно-реляционных связей (метаданные, аннотации); выбор стратегии выборки данных (комбинированные join-запросы или множественные запросы); проектирование алгоритмов неблокирующей сборки графа объектов из плоских результирующих наборов; разработка механизмов автоматической генерации SQL-запросов; определение метрик качества предложенного решения (объем шаблонного кода, сложность разработки) и их оценка.
